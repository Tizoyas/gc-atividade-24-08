# Labels do repositório

As labels classificam as issues e facilitam a organização das tarefas do grupo.

| Label | Finalidade |
|---|---|
| feature | Identificar tarefas de criação de funcionalidades ou melhorias no sistema. |
| bug | Identificar erros e problemas que precisam ser corrigidos. |
| docs | Identificar tarefas de criação, revisão ou atualização da documentação do projeto. |

Cada issue deve receber pelo menos uma label correspondente ao tipo de trabalho.
